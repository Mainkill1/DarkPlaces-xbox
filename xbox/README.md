# Xbox Port Directory

This directory is reserved for the nxdk build entry point, Xbox feature policy, native NV2A shaders, and host-side content tools.

It intentionally contains no fake build target yet. The first implementation issue must add a minimal nxdk target that produces and boots an XBE/XISO before DarkPlaces object files are introduced.
